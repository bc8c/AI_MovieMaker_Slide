P01 · STORY

바꿀 것은 WORLD / GENRE / STORY FLOW / 한 줄 아이디어 네 곳뿐!

AI PROMPT
나는 30초 정도의 짧은 AI 영화를 만들려고 해.

[나의 설정]
WORLD : {WORLD}
GENRE : {GENRE}
STORY FLOW : {FLOW}
한 줄 아이디어 : {IDEA}

내 아이디어의 핵심은 바꾸지 말고, 30초 영상으로 만들기 좋은 3개의 장면으로 이야기를 발전시켜줘.

[구성]
SCENE 1 : 이야기의 시작
SCENE 2 : 가장 중요한 사건
SCENE 3 : 결말

[조건]
- 각 장면은 약 10초 영상으로 표현할 수 있게 해줘.
- 등장인물은 가능하면 1명으로 유지해줘.
- 장소를 너무 많이 바꾸지 마.
- 한 장면에는 중요한 사건 하나만 넣어줘.
- 추상적인 설명보다 실제 행동과 상황으로 표현해줘.
- 장르와 STORY FLOW가 명확하게 느껴지게 해줘.
- 새로운 설정을 지나치게 추가하지 마.

각 장면은 아래 형식으로 작성해줘.
장면 제목 / 장소 / 등장인물 / 주요 행동 / 장면 내용

P05-A · MOTION DESIGN · GEMINI

완성된 이미지는 그대로 두고 움직임만 설계합니다.

AI PROMPT
이제 내가 만든 3개의 장면 이미지를 각각 짧은 AI 영상으로 만들려고 해.

[나의 이야기]
SCENE 1 {내용}
SCENE 2 {내용}
SCENE 3 {내용}

각 장면 이미지는 이미 완성되어 있으므로 이미지의 모습이나 구도를 새로 설명하지 말고, 각 장면에서 어떤 움직임이 일어나야 하는지만 설계해줘.

각 장면마다 다음 세 가지를 작성해줘.
1. CHARACTER ACTION
2. ENVIRONMENT MOTION
3. CAMERA MOTION

[중요]
- 한 장면에는 하나의 핵심 행동을 중심으로 구성해줘.
- 너무 많은 움직임을 동시에 넣지 마.
- 약 10초 영상으로 표현하기 쉽게 만들어줘.
- 갑작스럽거나 과도한 움직임보다 자연스럽고 단순하게.
- 원래 3장면 이야기 흐름을 바꾸지 마.
- 이미지에 없는 새로운 등장인물이나 중요한 사물을 추가하지 마.
- 세 영상을 연결했을 때 하나의 이야기처럼 이어지게 해줘.
